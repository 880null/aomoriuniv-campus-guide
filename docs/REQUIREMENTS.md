# 要件

## 必須動作
1. Macのstart.command / Windowsのstart.batでPython環境・依存関係を確認して起動する。
2. Arduino接続を試み、ローカルFlaskアプリを配信しブラウザを開く。
3. 未接続時にも検索と施設閲覧を利用できる。
4. 公式案内図の施設を一覧表示し、全体図で位置を確認できる施設は地図からも選択できる。
5. 建物名、地図記号、確認済みの教室番号・施設名で検索できる。階別一覧と出典PDFを表示する。
6. 選択した施設の名前・記号・LED状態を表示する。
7. 実機が応答した場合に対応LEDの点灯を表示する。
8. 全消灯、接続状態表示、エラー表示、手動再接続ができる。
9. 明示的なシミュレーション切替により、実機なしで画面上の点灯を確認できる。

| 記号 | 施設 | ピン |
| --- | --- | --- |
| A | 1号館 | D2 |
| B | 3号館 | D3 |
| C | 4号館 | LED未実装（実機対象外） |
| D | 5号館 | D4 |
| E | 6号館 | D5 |
| F | 7号館 | D6 |
| H | レストラン棟 | D7（仮設定） |

実装担当者の共有とユーザー指定に更新。実機LEDは6施設。画面は14施設・369地点を案内し、従来の7施設はシミュレーションで点灯表示する。追加施設は画面案内のみ。
4号館はLED未実装のため点灯命令を送らない。レストラン棟はD7に仮設定し、画面と仕様書で実配線未確認と区別する。

2号館、図書館新館、体育館、創薬棟、新研究棟、弓道場は点灯対象外。画面案内は利用できる。
公式案内図全11点・15ページの転記範囲と未記載情報はROOM_DATA.mdに記録する。
教室番号の先頭桁などから建物を推測しない。未登録教室には「教室情報は未登録」と表示する。

## 非機能要件
- Python 3.10以上、Flask、pySerial。画面はHTML5/CSS3/JavaScript/Fetch API。
- Uno R3、9600bps、8N1。通信エラー時に無限待ちしない。
- シリアル操作をロックで直列化し、ACKによって確定する。
- ローカルホスト専用、デバッグ・自動リロードなし。外部CDN不要。
- レスポンシブ表示、キーボード操作、読み上げ用ラベル、色以外の状態表示。
- UTF-8、日本語コメント、JSONによるデータ管理。
- 依存パッケージの初回取得はインターネットが必要。導入後は地図を含めオフラインで利用可能。

## 受入確認
- シミュレーション: 7施設を順に選び、常に1つだけ点灯表示。消灯後は0個。
- 検索: 全角数字・空白の正規化、建物／施設名、登録155番号すべて、同名室の区別、未登録番号の表示。
- 原図: 11PDF・15ページの転記と全369地点の到達性、原図ハッシュ、階・棟の未記載、階別一覧、オフラインPDFを確認する。
- 画面案内のみの施設へ移ると、以前の行き先のLEDを消灯する。
- 通信代替テスト: ACK、タイムアウト、不正応答、切断、ポート候補の曖昧さ。
- 実機確認: 起動時消灯、設定した6ピン、ACK、未実装施設への命令拒否、USB抜去、再接続、停止時消灯、10秒間通信なしで消灯。
- Mac/Windowsそれぞれでワンクリック起動とブラウザ表示を確認。

実機、OSごとの起動確認はテスト結果と区別して報告する。
