# 企画経緯

- 2026年10月22日、第1回グループワークで企画。
- 授業: 青森大学「プログラミングワークショップⅡ」、下條クラス。
- 課題: Arduino、LED、スイッチ、センサー等を活用し「誰か1人のためになるもの」を制作する。
- 対象: 初来校の高校生、新入生、オープンキャンパス参加者。
- 下條先生の「青森県の観光地を地図上のLEDで案内するシステム」を参考とする。
- Webで施設や教室を探し、実物のキャンパスマップの建物LEDで場所を知らせる。
- 初回にUnoへファームウェアを書き込み、展示時はUSB接続と起動ファイル実行だけで利用する。

## 現在の情報と未確認事項
7施設の記号は公式アクセスページの画像でも確認した。
配線は実装担当者からの共有に合わせ、1号館=D2、3号館=D3、5号館=D4、6号館=D5、7号館=D6へ更新した。
その後、ユーザーから4号館はLED未実装との共有があり、実機点灯は対象外とした。
レストラン棟は一時D7へ仮設定したが、2026-11-05にユーザーが未実装と確認。Hのpinはnullへ変更し、D2〜D6の5本を使用する。
2026-11-01、公式アクセスページの全11案内図・15ページから369地点（番号付き155室）を転記。館内の現地照合は未実施。図面で棟・階が分からない箇所はnullとし、推測しない。詳細は[教室データ](ROOM_DATA.md)。
展示用PC、実際の配線、LED、USB機器を使った動作確認は別途必要。
