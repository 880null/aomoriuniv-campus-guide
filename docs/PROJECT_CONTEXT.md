# 企画経緯

- 2026年10月22日、第1回グループワークで企画。
- 授業: 青森大学「プログラミングワークショップⅡ」、下條クラス。
- 課題: Arduino、LED、スイッチ、センサー等を活用し「誰か1人のためになるもの」を制作する。
- 対象: 初来校の高校生、新入生、オープンキャンパス参加者。
- 下條先生の「青森県の観光地を地図上のLEDで案内するシステム」を参考とする。
- Webで施設や教室を探し、実物のキャンパスマップの建物LEDで場所を知らせる。
- 初回にUnoへファームウェアを書き込み、展示時はUSB接続と起動ファイル実行だけで利用する。
