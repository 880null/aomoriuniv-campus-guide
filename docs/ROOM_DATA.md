## 転記の範囲

- 室名・室番号・用途が記載された教室、実習／研究室、事務室、会議室、支援施設、図書館、運動施設、トイレ、ELV、倉庫、ホール、玄関、テラス等を登録した。用途不明でも印字された番号は残す（761〜763等）。名称・番号のない区画は追加しない。
- 同名の無番号室は元図の区画ごとにIDと位置補足を持つ。「右側上段」等は図面上の位置を説明した補足であり、公式の部屋名や新しい部屋番号ではない。複数区画を1つの施設名と矢印で示す総合研究所は1施設として扱う。
- 吹抜とステージ上部は床のある目的室ではないため除外。表題・階数・方向案内（6号館へ）、壁・階段等の無名記号も独立した室として登録しない。
- A案内図にある1号館と本館の明記された区画はA。新研究棟・弓道場・2号館は別施設として扱う。2号館は1・2階の図はあるが個別室の名称・番号がなく、原図閲覧のみ。全体地図から位置を確定できないためマーカーなし。
- A案内図の左下の書庫2区画、家政・調理実習室、右上の「体育館」は棟記号との対応が明記されていない。building_id=nullと注記を残し、1号館・第1体育館・第2体育館のどれかへ推測で結び付けない。該当PDFから確認できる。
- 原図で階が確定できない区画はfloor=null。「集いのスペース」は表題にあるが階・区画が個別に示されていないため階未記載。A図の体育館ギャラリーも階未記載。I専用図のギャラリーは明記された2階を登録する。
- 340・350教室は3号館の2階。5304は第1ファブスペース。第2ファブスペースは5号館6階の番号未記載区画。713や5608等の欠番は補完しない。
- 全体図のA〜Kは公式の記号。新研究棟・弓道場の「新」「弓」は画面操作用の略記であり、公式記号を追加したものではない。

## データと再現方法

`data/floorplan_sources.json`にURL・取得日・ページ数・SHA-256、`frontend/static/floorplans/`に未加工の原図を保存する。原図の権利は青森大学に帰属する。独自制作の図面として扱わない。既存の地図と同様、学内展示を越える公開・再配布の条件は大学に確認する。

`data/extraction/A.json`〜`K.json`が目視転記の元データ。groupに棟・階・ページ・補足、entryに名前・番号・別名・分類・図上位置を持つ。無番号／未記載はnull。`floor_override`は倉庫に明記された地下1階のような個別注記だけに使う。source内に確認済みページと除外したラベルを記録する。

```sh
python scripts/build_room_catalog.py
python scripts/build_room_catalog.py --check
```

検索用`data/rooms.json`は生成物。各地点にID、棟、階、出典URL、ページ、確認日、ローカルPDFリンクを付ける。元データの追加・並べ替えにより無番号室のIDは変わり得るため、外部の永続キーとして使用しない。

数値単独の検索は登録番号の完全一致。全角・空白を正規化する。施設名・建物名・階を組み合わせて検索できる。原図で名称が同じ区画は統合せず、建物／階／位置を添えて候補表示する。LEDは建物の案内に限り、館内の位置は原図で確認する。
